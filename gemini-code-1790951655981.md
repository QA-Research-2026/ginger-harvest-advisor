## 1. Project Specifications
* **Project Name:** `ginger-harvest-advisor`
* **Tech Stack:** Next.js 14+ (App Router), React, Tailwind CSS, Google Gemini Gen AI SDK (`@google/genai`).
* **Domain Context:** An agricultural dashboard for Sunil P., a ginger farmer with a 0.5-acre plot in Sri Lanka. 
* **Core Logic:** Calculate a 1,500 kg/acre seed rhizome retention rule (750 kg total), subtract it from the estimated yield, and pass the remaining commercial yield to Gemini 2.5 Flash to generate a staged dispatch schedule based on simulated market data.
* **Mandatory Requirement:** The API route MUST include a `try/catch` block. If the API key is missing or the network fails, it must fall back to a deterministic JSON object returning static agronomic advice.

### Step 3: Implement the Backend Route
**File:** `app/api/schedule/route.js`
**Action:** Create a Next.js `POST` API route.
**Requirements:**
1. Import `GoogleGenAI` from `@google/genai` and initialize it.
2. Read the request JSON (`plotSize`, `estimatedTotalYieldKg`, `currentSpotPriceLkr`, `maturityWeek`, `weatherRisk`).
3. Calculate `seedRhizomeRequiredKg` (`plotSize` * 1500) and `commercialYieldKg` (`estimatedTotalYieldKg` - `seedRhizomeRequiredKg`).
4. Construct a prompt injecting the farm variables and the imported `gingerMarketData.json`.
5. Call `ai.models.generateContent` using the `gemini-2.5-flash` model. 
6. **Crucial:** Enforce a JSON schema via the model configuration `responseSchema` property containing: `marketAssessment` (string), `seedStockStorageProtocol` (string), `harvestSchedule` (array of objects containing `stage`, `timelineWindow`, `percentageCommercialStock`, `volumeKg`, `targetMarket`, `actionReasoning`), and `projectedGrossRevenueLkr` (number).
7. Return the parsed JSON with a `status: 'success'` wrapper.
8. **Catch Block:** If an error occurs (e.g., missing API key), catch it and return a hardcoded 200 OK response with `status: 'fallback'`, `fallbackNotice: 'AI inference service unreachable. Output generated via standard agronomic rules.'`, and a mock payload matching the JSON schema.

### Step 4: Build the Dashboard UI
**File:** `app/page.js`
**Action:** Replace the default Next.js page with a React Client Component (`'use client';`).
**Requirements:**
1. Create state variables for the 5 inputs: Plot Area (default 0.5), Estimated Yield (default 3500), Spot Price (default 850), Maturity Week (default 38), and Weather Forecast (dropdown: Dry/Stable, Moderate Rain, Heavy Monsoon Risk).
2. Create state for `loading` and `result`.
3. Build a `fetchSchedule` async function that POSTs to `/api/schedule`. Trigger it on component mount (`useEffect`) and via a "Re-calculate Strategy" button.
4. **UI Layout (Tailwind CSS - Dark Theme):**

   * **Timeline Table:** An HTML `<table>` iterating over `result.data.harvestSchedule` to show the multi-stage dispatch plan.
   * **Storage Note:** A bottom section displaying `result.data.seedStockStorageProtocol`.
